# 0.13.0 — connect declared quantities between modules

The workbench supports one explicit A → B or B → A connection. All eighteen
installed modules declare quantities with a type, unit, meaning, and input or
output key. A source input or calculated result can drive a receiving input
only when the declared type and unit match and the receiving model accepts
the current value. No conversion, rounding, or clamping is applied.

An invalid range or domain pauses the connection and keeps the last valid
receiving value. Valid values resume it automatically. Editing the receiving
quantity disconnects; other receiver controls and view changes preserve the
connection. Module replacement, slot removal, or leaving the workbench closes
it. There are no cycles or multiple simultaneous links.

Reusable quantity metadata, a pure link validator/session, and a scoped
connection panel extend the shared host. Incoming writes pause receiving
playback while retaining its view and comparison pin, and use the existing
smooth follower and 250 ms numerical text cadence without recursive change
callbacks. The nineteenth-module sandbox remains an independent-instance
example; it does not acquire the workbench connection UI.

Workspace links last only for the current workbench visit. Workspace backup,
selected representations, and linked configurations are not yet part of the
notebook. Content remains eighteen draft cards, 94 worked examples, 122 model
fixtures, and 112 static written exports. Independent mathematics/history
review, broader accessibility qualification, and live BOH retrieval remain open.
