# Build review and updated matrices — 0.16.0

Reviewed on 2026-10-26. This build refreshes the illustrations, brings the
original three cards' remaining mechanics and implementation metadata up to
date, adds settled model-data tables, and introduces a connected Mathematics
Atlas. It preserves all 22 model identities/versions and the 47 representations.
