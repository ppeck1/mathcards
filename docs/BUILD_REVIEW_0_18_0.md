# Build review and updated matrices — 0.18.0

Reviewed on 2026-10-26. This build expands linear algebra through four providers
using the existing playground contract, and adds a searchable definition index
connected to the cards and atlas. The earlier Geometry, Graph and three genuine
3D representations remain available.

The canonical collection has **26 draft cards, 134 worked examples, 202 numeric
fixtures and 33 sources**. Its 189-row inventory contains 26 draft specimens and
163 planned concepts. The written projection has 160 deterministic BOH documents.
The interface has 55 views: 26 Geometry, 26 Graph and three 3D. The landscape
retains 24 selectable areas across eight territories. The index has 186 entries:
174 authored definitions and 12 entries retaining exact card notation, with all
24 lowercase Greek letter names included. Index reference links and the 33
canonical source records are separate collections.

## What works and what remains limited

| Area | Working in this build | Remaining or limited |
|---|---|---|
| Coherent concept expansion | Vectors, Dot product, Matrix linear maps and Determinant add 20 original worked examples and 41 numeric fixtures | All four remain draft; independent mathematical review and historical research are pending |
| Plug-in playground | Each new provider declares controls, evaluation, readouts, Geometry and Graph; existing host owns input, motion, playback, pins and lifecycle | Registration alone does not supply a canonical card, source evidence, port meaning or publication approval |
| Story → formula → shape | Four new four-step illustrative stories use the shared calculation trace and authored quantity marks | These are stipulated teaching scenarios; their numbers are not measurements of observed systems |
| Vector and dot mechanics | Signed components change arrows and length; dot product follows component products and projection | Zero vector has no direction angle; projection onto zero is undefined although its dot product is valid |
| Matrix and determinant mechanics | Matrix columns move the basis, grid, input arrow and unit square; signed determinant is separated from nonnegative area | Live models are real and two-dimensional with bounded controls; arbitrary matrix sizes, translations and inverse calculation are outside scope |
| Representations | 26 Geometry and 26 Graph views share model state; original composition, logarithm and derivative keep their distinct 3D views | The new modules do not add 3D; the matrix graph follows mapped horizontal output while its scene/readout retain both coordinates |
| Readable continuous motion | New modules use existing geometry transitions, retained scene marks, paced numbers and reduced-motion behavior | Readability, comprehension and physical-device interaction still need learner and accessibility qualification |
| Definition index | Searchable meanings, examples, sources, symbol browsing, A–Z, field filters and links to cards that use a term; each card has a Definitions section | A growing reference for this collection, not a complete mathematics dictionary; background entries can have no current card use |
| Context-sensitive notation | Exact card notation retains local meanings; lowercase Greek names and common capital forms distinguish δ, Δ and ∂ | A shared spelling does not establish a shared quantity, unit or mathematical role |
| Search | Common header and full results page search definitions, available cards and atlas areas; Explore, index and map retain focused searches | Search is local matching and navigation; aliases are not mathematical equivalences, and planned areas do not become implemented cards |
| Atlas | Eight territories and 24 selectable areas retained; linear algebra placement opens the new available concepts alongside related lessons | Geographic placement is editorial and overlapping; relation-level filtering and a multi-concept comparison matrix remain |
| Private work | Existing notebook/workspace boundaries, version checks and explicit quantity connections remain the shared mechanism | No automatic wiring by matching names, implicit unit conversion or new claim of empirical equivalence |
| Validation | Actual schema/reference/AST checks and all 202 numeric fixtures pass; deterministic export and complete string payload preservation pass | Final release-wide test totals and any browser evidence belong in the release verification record; automated checks do not establish independent content review or teaching effectiveness |
