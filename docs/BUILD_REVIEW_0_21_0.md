descent extend the connected calculus sequence through separate model, story,
canonical-content, preview, index and map modules. The common playground owns
interaction, motion, readable values and saved configuration.

fixtures, 42 canonical sources and 214 written BOH documents**. Its 192 coverage
rows contain 35 draft specimens and 157 planned concepts. There are 77 views:
35 Geometry, 35 Graph and seven genuine Spatial views. Eight territories and

[0.20.0 checkpoint](NOTATION_COVERAGE_0_20_0.json) remain separate from the

across 876 forms, with zero unresolved/callable-review items, including the
shifted-log display. Actual final checks and browser observations are recorded in [release verification](VALIDATION_0_21_0.md).

## What works and what remains limited

| Area | Working in this build | Limitation or remaining qualification |
|---|---|---|
| Directional derivative | A degree-valued heading creates a unit direction; both gradient-component products combine into one signed local slope | The field is the bounded quadratic family F=c+ax²+by². Equal coordinate scales, unit direction and differentiability are explicit; the arrow is not a simulated route |
| Tangent plane | Base height and two local slopes produce a predicted target height. Actual height and actual-minus-predicted residual remain separate | Only the selected quadratic family is executable. A tangent plane is local; the exact quadratic remainder is not a general error formula |
| Gradient descent | Numbered exact iterates apply a fixed learning rate to a strictly positive quadratic cost. Cost, gradient, current iterate and next iterate remain distinct | No arbitrary objectives, constraints, stochastic training, momentum, line search or general convergence guarantee |
| Readable cost graph | The horizontal axis is learning rate; the vertical axis explicitly shows ln(1+C) of normalized cost after fixed integer k. Exact C remains the primary output and table quantity | This is a declared display transformation. Physically dimensioned costs require explicit reference-cost normalization before logarithms |
| Stable and oversized steps | Contraction, zero-step, boundary oscillation and growth examples show why direction alone does not select a safe step size | The all-start convergence interval 0<η<2/max(a,b) is derived for this particular positive quadratic, not every differentiable objective |
| Discrete mathematical states | The iteration control is whole-number only; its generic discrete descriptor blocks interpolation. Smooth learning-rate sweeps recompute exact fixed-length runs | Path connectors are visual aids. They do not represent fractional updates or a continuous-time trajectory |
| Shared field mathematics | Direction and plane lessons reuse the existing pure height/partial evaluator, surface mesh and camera projection | Shared helpers do not merge different primary quantities or learning purposes; each lesson retains its own contract |
| Distinct views | All 35 topics have Geometry and Graph; direction and plane add actual surface views, bringing Spatial to seven | Descent has Geometry and Graph only. A new view still needs a distinct mathematical role and accessible interpretation |
| Connected stories | Three new four-step narratives, calculation phases and exact quantity marks join the selected variable in text to the changing scene | Terrain and calibration scenarios use stipulated models and units; they are not measured datasets or equipment recommendations |
| Readable motion | The existing follower, stable text updates and number pacing remain in the host; algorithmic state changes preserve integer semantics | Learner comprehension and comfort still need direct observation across devices and access needs |
| Reference and search | New vocabulary and exact symbols link to real authored card usage. Cost C, integer k, residual R, gradient and unit direction keep local roles | Ambiguous spellings require continuing contextual review; related definitions remain editorial guidance rather than mathematical implication |
| Atlas and previews | New cards have model-based compact illustrations, explicit field memberships and area placements. Gradient descent moves from planned to available | The map covers selected neighborhoods, with 73 mapped planned concepts rather than the entire 192-row inventory or all mathematics |
| Ports and saved state | Existing typed quantities, comparison pins, camera/view state and revision-1 workspace mechanisms are reused | Equal names never create implicit wiring or unit conversion. Cross-concept usefulness and physical-browser recovery need broader qualification |
| Continuing notation | The expanded gate passes across 22,182 fields and 36,609 mathematical occurrences, including the explicit log display; exact local meanings and UI exclusions remain explicit | This is finite current-app/reference coverage, not a universal mathematical dictionary |
| Mathematical evidence | All 674 JavaScript tests pass; all 36 new fixtures and 15 presets agree with the pure provider, with scalar/vector, residual and discrete-state checks | Numeric agreement is not independent mathematical, historical or pedagogical review; final suite/browser evidence is tracked separately |

## Principles to add or enforce next

| Priority | Principle | Current status | Concrete next step |
|---|---|---|---|
| 1 | One mathematical state feeds story, formula and scene | Implemented through shared evaluated quantities and semantic marks | Keep every new story token and grammar binding attached to a visible, correctly typed quantity |
| 1 | A discrete control declares its domain | Integer iteration is explicit and interpolation is blocked generically | Require future algorithms to distinguish exact state changes from visual transitions and continuous tuning controls |
| 1 | A unit direction is a mathematical condition | Directional slope uses normalized cosine/sine components | Keep normalization, coordinate metric and evaluation point visible; do not substitute an arbitrary arrow without changing the rate interpretation |
| 1 | Local direction does not choose a safe finite step | Descent examples include zero, boundary and oversized steps | Retain step-size assumptions alongside any convergence or improvement claim |
| 1 | Prediction differs from observation or exact evaluation | Tangent-plane predicted height, actual height and residual are separate | Keep the residual's sign convention stable through text, formula, graph, ports and saved observations |
| 1 | Scalar cost differs from a vector gradient | Explicit cost root and two-component gradient bindings | Preserve result types when adding objectives, comparison quantities or connections |
| 1 | A shared kernel can support several lessons | Existing field helpers feed direction and plane modules | Reuse pure calculations without accumulating topic-specific branches in the playground host |
| 1 | Drawing limits do not alter mathematical values | Descent keeps full values when geometry needs clipping | Label visual limits and preserve honest numeric/table alternatives instead of silently capping results |
| 1 | A bounded example states the broader conditions | Quadratic-family and differentiability limits are explicit | Avoid promoting a restricted exact error or contraction identity into a theorem about arbitrary functions |
| 2 | A graph names the quantity it displays | Descent declares ln(1+C) while exact C stays available | Preserve normalization, the shifted-zero convention and the distinction between display values and model outputs |
| 2 | Every new term arrives with a usable route | New readers provide definitions, exact aliases and real card links | Check words introduced by explanatory prose as carefully as displayed symbols and formulas |
| 2 | Extra dimensions earn a learning role | Direction and plane have real surface information; descent retains two views | Add another representation only when it reveals a distinct relationship and can be explained accessibly |
| Next | Learning and access require direct qualification | Remains open under T12 | Observe learners tracing local quantities, reading signed error and comparing exact discrete runs |
| Next | Passed tests and draft count do not replace review | Independent mathematics/history review remains open | Preserve explicit review status and claim-level historical evidence while continuing coherent expansion |
