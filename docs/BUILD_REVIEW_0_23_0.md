# 0.23 terrain and startup preview

This branch is an isolated design preview based on 0.22.0. It changes navigation,
startup and presentation; it adds no teaching cards or inferred relationships.
The collection still contains 38 draft cards, 194 worked examples and 409
reference entries. The eight territories, 24 areas and canonical memberships
remain intact. Main continues to serve the published demo until this is merged.

## Principles carried forward

| Principle | Implementation rule |
|---|---|
| Compile deterministic work once | Reference links and terrain are built from editable sources, rather than regenerated by interaction |
| Keep geography separate from meaning | Terrain position/elevation are illustrative; memberships and explained concept edges stay with their providers |
| One changing situation | Story text, formula, chart and readable values use the same mathematical frame |
| Progressive disclosure | Show the primary action; retain calculation detail, native navigation and advanced playground controls on demand |
| Readability before inventory | Stable numbers, readable selected labels and ordinary language carry the explanation |
| Measure the actual boundary | CPU bootstrap, browser content readiness and real-device usability are different claims |

## Measurements and limits

The shared compiler measured approximately 22,845 ms before caching repeated
notation normalization and 1,621 ms afterward. JSON round-trip plus hydration
measured about 18.6 ms. The committed regression test budgets 1,500 ms for
parsing/setup, provider creation, hydration and search initialization. It fails
if browser startup calls the compiler. That CPU test excludes layout and paint.

In one instrumented local Chrome comparison, the saved standalone baseline
reached DOMContentLoaded with populated main content in 76,317 ms, versus
655.5 ms for the rebuilt app. This is one pair of fresh local navigations with
no applied CPU/network throttling, not a cross-device or percentile claim.
Test-only instrumentation lives in ignored QA fixtures. See the
[measurement record](terrain-preview/startup-measurements.json).

The ordinary build verifies the terrain cache in under 0.01 s; a full 768 × 512
bake measured 28.53 s. The generated module is 275,900 bytes, including a
177,345-byte PNG and 36,031 bytes of contour paths. The standalone preview is
about 3.5 MB before transport compression and retains all assets offline.
