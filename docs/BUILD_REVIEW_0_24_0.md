# 0.24 clarity review

This release keeps the 38 draft concepts, 194 worked examples, reference index
and shared mathematical models. It corrects presentation rather than adding
new concepts or new mathematical relationships.

| Finding | Change | Verification |
|---|---|---|
| Desktop chart was weaker than phone | One comparison renderer; large Selected/All means on both sizes | 1366 × 768 browser view shows the chart and its mass control above the fold |
| Duplicate mass controls and results | One guided HTML slider, one play/pause action, one mean comparison group | Actual story markup and renderer contracts; browser control counts |
| Programming names appeared in explanations | Use x, n, x̄, μ and the declared sums; notation tables for given values/expression parts | Presentation tests plus unchanged model input keys and numeric cases |
| Decorative elevation conveyed no mathematical quantity | Flat categorical field map; relief assets excluded from runtime | No raster relief or contour rendering; categories are labeled |
| Phone overview hid six territories | Whole-world camera on every viewport; compact map and complete native key | Eight visible labels at narrow widths; no initial crop |
| Version and portfolio drift | Package version drives generated identities; portfolio describes current features | Build consistency tests and fresh demo launch key |

| Remaining work | Scope |
|---|---|
| Physical-device qualification | Real touch, rotation and screen-reader walkthroughs remain distinct from browser-width tests |
| Learning and mathematical review | The existing draft/prototype status remains; automated checks do not establish learning effectiveness or theorem/history review |
| Future concepts | Extend models, stories, reference terms and validation together rather than creating parallel card-specific hosts |

| Principle | Rule |
|---|---|
| Visual meaning | Shape/position in a lesson encodes its declared quantity; the flat atlas identifies categorical destinations |
| One primary action | A variable has one primary guided control; advanced playgrounds remain optional |
| Declared notation | Translate model keys through explicit bindings, never invent mathematical meanings from code names |
| One release identity | Read `package.json`; generate other labels and artifact names |
| Reusable presentation | The laptop and phone chart share one renderer and one evaluated model |
