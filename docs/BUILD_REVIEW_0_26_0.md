# 0.26 concept expansion review

All 24 atlas areas already had an introduction. This batch deepens the thinner
Chance and Computation territories rather than treating one available lesson
as complete coverage of a subject. It adds three concepts, fifteen original
examples, thirty-six numeric fixtures and six views through the existing host.

The collection now contains 41 draft cards, 209 examples, 382 numeric fixtures,
52 source records and 89 views. The index has 426 entries and its visual catalog
has 552 selectable forms. Chance grows from 3 to 5 available lessons,
Computation from 2 to 3, and Change from 13 to 14 through overlapping membership.

| Gap | Added lesson | What the learner changes and sees |
|---|---|---|
| Conditional probability beyond the existing Bayes example | Conditional probability | Narrow an inspection window on a uniformly sampled proof strip; follow overlap and window probabilities into their ratio and a normalized frame |
| Spread beyond the existing mean comparison | Variance and standard deviation | Adjust one of four known cut lengths; follow the moving mean, signed deviations and their square areas into variance and standard deviation |
| Repeated updates beyond one linear scan | Recurrence relations | Change the fraction retained in a reservoir; follow retention and refill through exact whole-number rounds |

| Working contract | How the batch preserves it |
|---|---|
| Simple guided story | One primary variable control and a shared compact lesson layout; calculation detail and the advanced playground stay optional |
| Connected representations | Geometry and Graph read the same evaluated model, with declared units and semantic quantity marks |
| Exact domains | Zero-probability conditioning is undefined; variance describes the complete four-item group; recurrence rounds stay integer |
| Plug-in boundaries | `data-iteration.js` owns math and scenes; `data-iteration-stories.js` owns narrative; canonical JSON owns content; existing registries compose them |
| Searchable language | New definitions and forms extend the prepared index, which supplies the complete visual symbol catalog |
| Meaningful map | Actual memberships and availability update the map and summit counts; terrain is not a second content inventory |
| Evidence | Original examples and numeric fixtures are checked separately from the visual presentation; definition sources are recorded without claiming independent lesson review |

| Remaining priority | Reason and next step |
|---|---|
| Quantifiers and proof language | Foundations remains thin. A bounded every/some lesson can introduce quantification without presenting a finite animation as a general proof |
| Statistical inference | These lessons establish conditional ratios and descriptive spread. Estimation, sampling distributions and confidence intervals need their own assumptions and models |
| Broader algorithms | Recurrence is one exact first-order update family; it does not complete recurrence solving or general algorithm analysis |
| Physical-device and learning review | Browser checks and numeric agreement do not qualify touch hardware, screen readers or learning effectiveness |
| Independent mathematics/history review | Cards remain draft specimens; historical claims are not invented to fill the section |
