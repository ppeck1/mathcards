## What works and what remains

| Principle | Current result | Remaining limit |
|---|---|---|
| Plug-and-play families | One pure `reasoning.js` provider and one narrative provider supply four lessons through the existing host | Continue keeping topic-specific models and scenes out of shared host branches |
| Connected quantities | Story tokens, formulas, previews, pins, Geometry and Graph use the same evaluated parameters | Independent learner and mathematical review remains open |
| Exact logical behavior | Inclusive measurement boundaries select actual Boolean states; every truth assignment is checked | Three fixed formula pairs and three fixed argument patterns; no arbitrary formula parser or proof engine |
| Current versus global claims | Current truth, all-row equivalence and argument validity have separate labels and results | Validity alone does not establish empirical premises or soundness |
| Meaningful marks | Pair membership, truth regions and force components encode declared quantities | A finite relation count does not imply a probability distribution |
| Physical meaning and units | Torque preserves sign, application position, a perpendicular moment arm and labelled force/length scales | No friction, inertia, force-balance or door-motion prediction |
| Readable guided design | One primary slider, shared pacing and optional advanced playground | Physical touch and screen-reader qualification remain open |
| Scoped reference | 489 entries, 597 selectable forms and card-use links enter the prepared index and visual catalog | Reference coverage is not independent mathematical review |
| Honest roadmap | 42 topic rows link to draft introductions, 34 to precursors and 138 remain planned | All 214 topic scopes still require editorial review |
