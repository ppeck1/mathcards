# 0.30 probability, expectation and information

The Chance territory gains three connected introductions. They share a library
return-desk scenario: X is the number of books arriving at the next check-in,
with possible values 0, 1 and 2. The model specifies the chance q of exactly one
book and allocates the remaining mass between zero and two using r. This keeps
every supported input a valid distribution. When q=1, no remaining mass exists
and r has no effect.

## Added concepts

| Atlas gap | New lesson | Story, formula and visible change |
|---|---|---|
| General finite distributions beyond the existing binomial example | Probability distributions | Change the one-book chance; probability moves within one fixed whole and between three separate outcome masses |
| Expectation as its own reusable concept | Expected value | Shift mass from zero toward two books; follow the weighted contributions into a moving balance point that can lie between integer outcomes |
| Information and uncertainty | Shannon entropy | Move from certainty toward three equally likely outcomes; follow probability through surprisal into weighted contributions measured in bits |

## What works and what remains

| Principle | Current result | Remaining limit |
|---|---|---|
| Modularity | One pure probability family supplies three distinct models; narrative, records, reference language and map placement stay separate | Keep future joint distributions and sampling mechanisms separate from the shared host |
| Connected representations | Each model uses the same probability vector in stories, formulas, scenes, Graph and thumbnails | Learner studies, physical touch and independent mathematical review remain open |
| Meaningful shape | Strip lengths and mass heights encode probability; the balance point encodes expectation; contribution lengths encode information in bits | These are finite model quantities, not measured book-return frequencies |
| Honest graphs | A PMF is shown at separate outcomes; the expectation and entropy graphs sweep a model parameter | A line between outcomes must not suggest fractional book counts |
| Endpoint arithmetic | Impossible outcomes have zero entropy contribution; a positive event's surprisal is evaluated only at positive probability | The zero-term convention does not define log₂0 as a finite number |
| Distinct summaries | Expected book count and expected surprisal have different units and can vary independently | Entropy is neither a stock recommendation nor a thermodynamic quantity |
| Complete language | 554 index entries and 644 selectable notation forms include the new terms with actual card links | Every future notation change must pass the coverage audit |
| Book scope | MAT-052 and MAT-177 gain explicit prerequisites | Microcanonical entropy and the book's entropy of a form remain planned |
