# 0.31 joint models and conditional information

This batch follows the previous finite-distribution and entropy lessons into
two-variable probability. X records whether a return tray holds a book and Y
records whether its sensor lamp is on. The lamp flips its binary reading with
the same probability for an empty and occupied tray. This is an assumed model
for exploring information, rather than a fitted description of a real device.

## Added concepts

| Atlas gap | New lesson | Story, formula and visible change |
|---|---|---|
| Probability of two variables together | Joint distributions | Four joint masses move as the lamp's flip rate changes; row and column totals connect them to marginals and conditional readings |
| Uncertainty after learning an observation | Conditional entropy | Normalize the selected lamp column, compute each possible reading's entropy and weight those entropies into an average |
| Dependence as information | Mutual information | Split original uncertainty into remaining uncertainty and shared information; compare uninformative, faithful and perfectly inverted lamps |

## What works and what remains

| Principle | Current result | Remaining limit |
|---|---|---|
| Modularity | One pure binary-family provider and one narrative provider reuse the shared host | General joint-table editing and continuous distributions remain separate future modules |
| Connected quantities | Joint masses, marginal sums, conditionals and information summaries use the same inputs | No fitting to sensor observations or measured accuracy claim |
| Meaningful geometry | Probability and bits retain fixed scales; the selected conditional column stays distinct from the averaged result | Charts illustrate a finite family and do not replace general definitions or proofs |
| Readable guided stories | One visible flip-rate slider, paced values and visible inactive quantities | Physical touch, external accessibility qualification and learner studies remain open |
| Conditioning conditions | Impossible selected observations have null conditional readings and zero weight in the average | A zero-weight convention does not define a conditional law on an impossible event |
| Local versus average uncertainty | A particular observation can increase entropy; the average remaining entropy does not exceed the original entropy | Neither statement promises a particular realized return or predicts causal change |
| Labels versus information | A perfectly inverted known lamp rule can preserve full information despite zero literal accuracy | The examples are mathematical channels, not recommendations for deploying sensors |
| Scoped language | 573 entries and 661 selectable forms include joint, conditional and mutual-information notation with actual card links | The calculus chain rule, self-information and perpendicular-vector readings retain their distinct meanings |
| Honest roadmap | MAT-052 and MAT-177 gain richer precursor links | Microcanonical entropy and the book's entropy of a form remain planned |
