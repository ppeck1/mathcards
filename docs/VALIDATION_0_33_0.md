# 0.33.0 validation record

## Results

- All 944 JavaScript tests pass. The full local run with two file workers took
  66.5 seconds. Startup used 273.6 ms against the unchanged 1500 ms budget.
- All 16 Python tests pass, including independent references, deterministic
  standalone builds, integrity failures and terrain invariants.
- All 622 canonical fixtures agree with the independent reference. Nine
  negative schema/reference mutations remain rejected.
- The notation audit resolves 55,982 occurrences across 1,177 forms, with zero
  unresolved forms or review items. The reference still has 599 entries and
  670 selectable forms across 428 meanings.
- All 61 canonical TeX definitions compile strictly to annotated native MathML.
  Tests check source annotations, fractions, sums, matrices, subscripts, inline
  use, unsafe commands, deterministic output and exclusion of the parser from
  the runtime bundle. The pinned compiler's license is retained.

## Regression coverage

Logarithm checks include exact integer powers, negative powers, reduced
power-of-two fractions, extreme represented numbers and nearby nonidentities.
Exact displays remain strings through the shared readout instead of turning
fractions into rounded decimals followed by an equality sign.

Preview tests retain model-derived values and fixed scales, enforce reserved
caption space and readable labels, and cover all 61 illustrations. A separate
static glyph-bound pass found no text collisions or horizontal overflow in the
61 rendered previews. The six reported cases were inspected as a scene board.

Actual story and calculation DOM tests exercise sign crossings, unary minus,
scientific notation, retained text nodes and signed accessibility labels.
Existing pacing and reduced-motion contracts remain covered. Legacy presets
load the correct finite quotient, analytic slope, corner or invalid-step state;
unrepresented functions and data types do not receive substitute presets.

Explore's actual filter/render handlers cover all atlas memberships, search,
paging and reset behavior. Other checks cover readable connection titles,
written examples, Index defaults, distinct Workbench modules, import labeling,
share metadata and seven metadata color pairs at 4.5:1 or better.

## Search performance

The exhaustive actual-index tests remain unchanged. Sharing query analysis
within one search reduced the isolated index test file from 87.29 to 17.61
seconds. The all-form lookup test fell from 72.82 to 4.92 seconds. All 36 tests
passed with the full corpus and every usage context retained. Caches are local
to a request and cannot accumulate across unrelated searches.

These are local Node measurements, not a physical-phone or throttled-browser
performance qualification. The compiled index remains ahead-of-time data.

## Generated-file integrity

The 0.32.0 Git blob reproduced the reported manifest mismatch: its recorded
index hash began `2179877f`, while the committed HTML began `c2f474be`.
Generated HTML and JSON now use explicit LF bytes, with Git attributes keeping
cross-platform checkouts consistent. Tests independently hash generated bytes
and reject corrupted or mismatched standalone files.

After the build and all content checks, CI inspects generated paths against
Git, including untracked files. The gate covers the catalog, reference index,
MathML data, editable version stamp, offline app, manifest, exports and notation
reports. The obsolete baked terrain file is removed; its archived mathematical
generator still has tests and writes ignored QA output by default.
