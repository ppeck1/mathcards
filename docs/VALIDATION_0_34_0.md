## Mathematics and interaction

exports and 175 representations: 84 Geometry, 84 Graph and seven Spatial.

Checks include exhaustive small sampling, binomial-test tails, interval tail
equations and weighted coverage, regression normal equations, undefined

analytic flow identities, differential-equation residuals, energy conservation,

polynomial residuals are tested. Nearness does not certify an exact double root.

scene bindings, typed ports, independent instances, sources and classic-script
order. The plug-in sandbox loads current providers without starting a clock.

inputs. Unknown story lookups do not expose inherited properties.

## Generated artifacts

Windows intermittently rejected generated overwrites during integration.
Generated-only helpers now skip identical bytes, stage beside the target,
close and atomically replace. Recognized Windows failures have at most three
attempts; unrelated or persistent failures propagate. There is no truncate-first
or unlink-destination fallback. Eight Node and seven Python fault tests verify
preservation, cleanup, retry bounds and failure behavior.

Atomicity is per file, not a transaction over the corpus. A finished build and
integrity/drift gates remain required. Deterministic export, repeated standalone
builds, actual-byte hashing and standalone parity pass. Private notebook and
workspace state remain outside corpus exports. BOH checks are static metadata
checks; live intake, indexing and retrieval were not exercised.
