## Mathematics and scope

Four lessons add 20 original examples, 256 independent numeric fixtures and
eight views. The candidate contains 130 draft lessons, 654 examples, 2,471
fixtures, 784 written exports and 267 views. Fourteen explicit metadata
families install 46 continuation lessons through the same host. Existing
model revisions and private-state schemas are retained.

LCM uses positive whole-minute periods from one to eight. The numerical
formula ab/gcd(a,b) returns the first positive common multiple. Zero remains
the common starting event. The independent oracle searches for the first
positive shared multiple rather than repeating the runtime gcd calculation.
All 64 supported period pairs are checked. Both signal rows and their common
events use a fixed 0–60 minute axis; the smallest returns retain visible marks
separate from zero. The graph contains integer input samples, not invented
fractional periods.

Perfect-number comparisons enumerate positive proper divisors of n, excluding
n itself. Their sum is compared exactly with n to distinguish deficient,
perfect and abundant cases. One has no proper divisors and sum zero. All sixty
supported numbers are checked with an independent factor-pair reference.
The declared 0–120 strip scale preserves actual lengths of the divisor-sum
and target bars. The finite family makes no general classification theorem
or current claim about open problems.

The convex regular polygon uses a positive circumradius and a whole side
count from three through twelve. Vertices lie on equal-scale metre axes.
Side length, apothem, perimeter, central angle and area remain separate.
The displayed triangles agree with the actual side count. An independent
reference uses vertex distances and shoelace area rather than the runtime
sine-area formula. Regression checks include radius/area scaling, special
triangles/squares/hexagons and invalid noninteger side counts.

Sphere measurement distinguishes the surface from its enclosed ball. A full
ideal tank has diameter 2r, surface area 4πr² and enclosed volume 4πr³/3.
The central disk has area πr². Its projected illustration does not stand in
for surface area or volume. Volume is additionally shown on a fixed 0–550 m³
bar and curve. The independent reference integrates central circular
cross-sections with exact rational coefficients. Length, square and cubic
units, scale factors and invalid radii have separate checks.

Definition-level sources are the original MathWorld reference pages for
[LCM](https://mathworld.wolfram.com/LeastCommonMultiple.html),
[perfect numbers](https://mathworld.wolfram.com/PerfectNumber.html),
[regular polygons](https://mathworld.wolfram.com/RegularPolygon.html) and
[spheres](https://mathworld.wolfram.com/Sphere.html), inspected 2026-11-05.
Scenarios, calculations, figures and examples are original constructions.
These citations do not verify the supplied books' exact editions or pages.
