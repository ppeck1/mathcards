## Mathematical checks

Neural summation separates two nonnegative dimensionless channels with fixed
gains. The net drive can be negative; it is not a firing rate or probability.
The five-site receptive field uses four negative surround weights and a fixed
positive center weight. Unit surround gain cancels every uniform brightness
level, while the all-black stimulus cancels at any gain. Independent rational
references, signal grids and actual drawing measures check these relationships.

The capacity lesson distinguishes actual input-mix information from the
maximum over input distributions in a known memoryless binary symmetric
channel. A uniform input attains capacity; a deterministic inversion remains
informative. Peer review found cancellation in an entropy subtraction for rare
inputs. Weighted Bernoulli divergences with stable near-equal series now retain
positive information at input chances down to 10⁻²⁴ in the tested family,
agreeing relatively with an 80-digit joint-distribution reference. Near-half
channel capacity also retains its stable series.

All 128 message/error states of the even-parity Hamming (7,4) family are
checked against an independent reference. Codewords have minimum distance
three. Under the declared no-error/one-flip assumption, the syndrome selects
the changed position and recovery restores all four data bits. Leading zeroes
are preserved through the shared template/readable-value formatting. No
multiple-error guarantee is inferred from these examples.

Photon calculations use exact SI defining constants and a separate joule to
electronvolt conversion. Strict relative comparisons for tiny joule/action
quantities cannot pass an incorrect zero by using a unit-scale absolute
tolerance. Independent high-precision references check fλ=c, E_J/f=h and the
joule/electronvolt conversion. The two-event clock comparison distinguishes
proper from coordinate intervals, including separate port types despite their
shared second unit. The reference also checks Lorentz scaling and limits.
